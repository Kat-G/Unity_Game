# Catch Game

Небольшая 2D-игра, разработанная на Unity с использованием C#.

## О проекте

Игрок управляет персонажем, который перемещается влево и вправо и ловит появляющиеся предметы. Среди них есть полезные и вредные предметы, влияющие на игровой процесс.

В игре реализованы:

- перемещение персонажа;
- игровая механика сбора предметов;
- полезные и вредные предметы;
- система жизней;
- система подсчёта очков;
- открытие новых фонов при достижении определённого количества очков;
- открытие новой фоновой музыки.

В дальнейших планах: реализовать бонусный режим при получении определенного количества очков.

## Технологии

- Unity
- C#
